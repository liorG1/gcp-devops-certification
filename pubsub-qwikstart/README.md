# Pub/Sub: Qwik Start - Console (CLI Version)

This lab demonstrates setting up Google Cloud Pub/Sub using the `gcloud` CLI tool via WSL and VS Code.

## Steps Performed:
1. Created a Pub/Sub Topic named `MyTopic`.
2. Created a Pull Subscription named `MySub`.
3. Published a "Hello World" message to the topic.
4. Pulled and acknowledged the message via the subscription.
5. Cleaned up resources to prevent unexpected charges.
