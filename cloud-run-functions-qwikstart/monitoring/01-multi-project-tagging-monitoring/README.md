# Multi-Project Tagging & Monitoring Lab (GCP & Terraform)

מעבדה זו מדגימה ארכיטקטורת ניטור מרכזית רב-פרויקטית (Multi-Project Monitoring) ב-Google Cloud, המבוססת על תיוג משאבים (Resource Labeling) וניהול דקלרטיבי באמצעות Terraform.

## הארכיטקטורה

הסביבה מורכבת משלושה פרויקטים נפרדים:
1. **פרויקט ניטור מרכזי (`terraform-learning`)**: משמש כ-Scoping Project. הוא אינו מכיל משאבי חישוב משל עצמו, אלא אוסף מטריקות ומנהל פוליסי התראה.
2. **פרויקט Worker 1 & Worker 2**: פרויקטים מבודדים המכילים שרתי Compute Engine (VMs) המריצים Nginx ומתוייגים לפי תפקידם וסביבתם.

---

## גישת השילוב: Linux (gcloud CLI) + Terraform (IaC)

במעבדה זו בחרנו בשילוב מנצח של שני עולמות האוטומציה כדי לעקוף מגבלות הרשאות בחשבון אישי (Free Tier) ולייצר תהליך עבודה יעיל:

### 1. השלב האימפרטיבי: Linux & gcloud CLI (`setup_infrastructure.sh`)
* **מה בוצע:** יצירת פרויקטים מאפס, שיוך לחשבון החיוב (Billing Account), הפעלת ה-APIs של Compute Engine, פתיחת חוקי פיירוול והקמת ה-VMs.
* **למה בלינוקס?** כדי ש-Terraform יוכל לנהל פרויקטים וחיוב, נדרשות הרשאות ניהוליות קיצוניות ברמת ה-Organization ב-GCP. בחשבון אישי, השימוש ב-`gcloud` המחובר ל-Identity האישי שלך מאפשר לבצע את הפעולות החד-פעמיות הללו במהירות ובקלות, ללא סיבוך של הגדרות IAM מורכבות ל-Service Account.
* **לוגיקת שיוך השרתים:** הסקריפט משתמש בשינוי ה-Context הדינמי של ה-CLI באמצעות הפקודה `gcloud config set project [PROJECT_ID]`. כל קבוצת פקודות רצה תחת הפרויקט הפעיל באותו רגע, מה שמבטיח שהמשאבים ישוייכו לפרויקט הנכון לפי סדר הפעולות בקובץ.

### 2. השלב הדקלרטיבי: Terraform (`main.tf` & `provider.tf`)
* **מה בוצע:** הגדרה והחלה של פוליסי התראה (Alerting Policies) עבור ניצול CPU גבוה וזמינות שרתים (Uptime Checks) המנטרים את הפרויקטים המרוחקים.
* **למה ב-Terraform?** התראות הן משאבים לוגיים שמשתנים לעיתים קרובות. Terraform מצטיין בניהול מצב (State Management). אם נרצה לשנות את סף ההתראה מ-80% ל-90%, Terraform ידע לעדכן (`update`) רק את הרכיב הספציפי בצורה חכמה, בניגוד לסקריפט Bash שהיה נאלץ למחוק וליצור מחדש (או להיכשל).

## קבצי המעבדה

* `setup_infrastructure.sh`: סקריפט הלינוקס להקמת הפרויקטים, השרתים והפיירוול.
* `provider.tf`: הגדרת ה-Google Provider לניהול המשאבים בפרויקט המרכזי.
* `main.tf`: הגדרת פוליסי ההתראה מבוססות הפילטרים והלייבלים מרחוק.
