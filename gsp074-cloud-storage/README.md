# GSP074 - Cloud Storage: Qwik Start - CLI/SDK

This lab demonstrates basic Google Cloud Storage operations using the `gcloud storage` CLI.

## Commands Executed:
- Created a bucket: `gcloud storage buckets create gs://<BUCKET_NAME>`
- Uploaded / Downloaded objects using `gcloud storage cp`
- Listed assets using `gcloud storage ls`
- Handled Public Access (ACLs) using `gcloud storage objects update`
- Removed assets using `gcloud storage rm`
